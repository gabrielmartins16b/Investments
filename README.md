# Investir Bem 📈

Site estático de educação financeira com trilha de aprendizado sobre investimentos no Brasil.

## Conteúdo

- Inflação e poder de compra
- Taxa Selic e CDI
- Tesouro Direto (Selic, IPCA+, Prefixado)
- CDB, LCI e LCA
- Ações (Buy and Hold, dividendos)
- ETFs (IVVB11, BOVA11)

## Como rodar localmente

Abra o arquivo `index.html` direto no navegador — sem dependências.

## Como publicar

### Netlify
1. Arraste a pasta do projeto em [netlify.com/drop](https://netlify.com/drop)

### Vercel
```bash
npx vercel
```

### GitHub Pages
1. Suba para um repositório público
2. Vá em Settings → Pages → selecione a branch `main`
